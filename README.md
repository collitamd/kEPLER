# Kepler · Citta-k

Astrología y Árbol de la Vida: versión web instalable (Android, iPhone y PC) del programa Kepler de Miguel García.

Abrir: https://collitamd.github.io/kEPLER/

Esta versión no contiene cartas personales: se cargan con «Cartas → Importar» y quedan guardadas solo en el equipo de quien la usa.
